# Tradutor de Palavras

Aplicativo Flutter de tela única desenvolvido para o Curso de Engenharia de Software da Católica SC, pela matéria "Desenvolvimento de Dispositivos Móveis"

Apresenta uma palavra em Português e permite visualizar suas traduções em
Inglês e Francês, com navegação entre uma lista de 11 palavras (lista
circular).

## Como executar

```
flutter pub get
flutter run
```
